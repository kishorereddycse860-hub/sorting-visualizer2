Project Objective

This project provides an interactive visual environment for understanding the working of fundamental sorting algorithms through real-time, step-by-step animation. Rather than reading through code or static explanations, students can watch each comparison, swap and placement happen on screen — building genuine intuition for how Bubble, Selection, Insertion, Merge and Quick Sort actually operate, and why each one behaves differently in the best, average and worst case.
